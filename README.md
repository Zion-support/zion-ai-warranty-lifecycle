# Zion AI Warranty Lifecycle

AI-powered warranty & EOL/EOSL lifecycle tracker for enterprise hardware fleets (HPE, Dell, Lenovo, NetApp + TPM providers).

**Live app:** https://zion-support.github.io/zion-ai-warranty-lifecycle/

## Features
- Coverage-gap radar against OEM warranty dates
- EOL/EOSL forecasting with refresh urgency
- Renewal risk scoring (asset age, criticality, failure history)
- Procurement-ready quote packs grouped by site/vendor
